    Relay setup

    A relay is a tiny free service that you own. It fetches feeds and articles for CyPress, which fixes most “won’t load” problems, including TechCrunch. It takes about five minutes.

    1. Create a free account at cloudflare.com, open Workers & Pages, and choose Create, then Worker.
    2. Replace the sample code with the code below, then deploy.
    3. Paste your worker address (it ends in workers.dev) below, then press Test.

    Your relay is running older code. Copy the code below, paste it over the old code in Cloudflare (Edit code), and press Deploy. It fixes more sites that block feed readers.

    Anyone who has your address can use it, so keep it private.

    To sync between devices

    1. Use the code above (it now includes sync). If you set up your relay before, paste it again and deploy.
    2. In Cloudflare, open Storage & Databases, then KV, and create a namespace named cypress-sync.
    3. Open your worker, go to Settings, then Bindings, add a KV namespace binding with the variable name SYNC, pick cypress-sync, and deploy.
    4. In CyPress Settings, open Sync and press Start sync. On your other device, press I have a code and type the code shown.
