Design principles applied

  • One job per widget. Top Story = one big story. Headlines = 3–4 stories. Ticker = breaking. No widget tries to do everything.
  • Three type roles max. Headline (semibold), source (small caps, muted), timestamp (faint). The eye knows what to read first.
  • No monotone wash. The old widgets were all dark green — hierarchy collapsed. These use tonal contrast: sage for the hero, white/dark surfaces for lists.
  • No dead space. The old 2×2 was 60% empty. If a widget is tall, it shows more stories.
  • The "Type" cover language in the Top Story widget makes it unmistakably CyPress — no other news widget looks like that.
  • Dark mode is designed, not inverted. Dark surfaces, desaturated accents, same hierarchy.
  • Every story is a 48dp tap target. Brand wordmark opens the app.
