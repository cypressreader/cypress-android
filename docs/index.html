CyPress

The news you follow, laid out like a magazine.

  • A front page built from today’s stories, with big photos and real headlines
  • Read-aloud that keeps playing with the screen off
  • Dozens of themes, from newsprint to neon
  • Add any site you like. No account needed
Get CyPress for Android

CyPress is Android-only for now. Open this page on an Android phone to install it.

How to install
  1. Tap the button. Your phone downloads a file called cypress.apk.
  2. Open it. If Android asks, allow your browser to install apps from this source.
  3. Tap Install, then open CyPress.
